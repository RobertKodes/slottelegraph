# slottelegraph

Live Solana mainnet as a **Victorian telegraph office** (Morse sounder + ticker tape).

The sounder/key advances with the slot clock. Tape lines are recent txs — ink by program family. Coil spark / heat ≈ fee pressure. Garbled or torn tape ≈ failed txs. Break key freezes the desk.

Not an explorer. Not a dashboard. Not a newspaper.
